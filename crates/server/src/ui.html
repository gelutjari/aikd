💡 Bagaimana AIKD Melakukan Scanning?
  1. Auto / Default Workspace: Membaca daftar folder di scan.include_paths (bisa diatur di tab Settings).
  2. Directed Scan: Anda atau AI Agent bisa men-scan folder mana saja kapan pun lewat kotak di samping atau tool MCP scan.
  3. Blake3 Incremental: Hanya file yang berubah hash-nya yang di-index ulang. Teks asli tetap di disk, DB tetap ramping!
